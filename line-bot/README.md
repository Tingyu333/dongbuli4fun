# 丼步喱・絆 LINE bot

在 LINE 裡問「空房」「擲杯」「天氣」「放假」「分帳」這些，bot 回覆（全部指令傳「說明」就會列出來）。可以加好友一對一聊，也可以拉進朋友的群組。

- **獨立的 Apps Script 專案**：不是網站後端那個，壞了也碰不到訂房和寄信。
- **只讀訂房 Sheet 的日期和狀態**：不寫任何東西，也不回任何名字、電話、Email。
- **只回覆、不主動推播**：Reply 不算進 LINE 免費方案每月 200 則的額度。

| 檔案 | 用途 |
| --- | --- |
| `Code.gs` | bot 程式，貼到新的 Apps Script 專案 |
| `richmenu.png` | 圖文選單的圖（2500×1686，大型 3×2 六格） |

## 設定步驟

### 1. 開 LINE 官方帳號，啟用 Messaging API

1. 到 [LINE Official Account Manager](https://manager.line.biz/) 建立官方帳號（免費方案就夠）。
2. 帳號的「設定 → Messaging API」→ 啟用 Messaging API，選一個 provider（選了不能改）。
3. 到 [LINE Developers Console](https://developers.line.biz/console/)，點進剛剛那個 channel 的「Messaging API」分頁，在最下面的 **Channel access token (long-lived)** 按 Issue，複製起來。

> 2024 年 9 月起不能直接在 Developers Console 建 Messaging API channel，一定要從官方帳號那邊啟用。

### 2. 建 bot 的 Apps Script 專案

1. 到 [script.google.com](https://script.google.com/) →「新專案」，取名「丼步喱 LINE bot」。
2. 把 `Code.gs` 整份貼進去，儲存。
3. 左側「專案設定」（齒輪）→ 最下方「指令碼屬性」，新增三個：
   - `LINE_CHANNEL_ACCESS_TOKEN`：步驟 1 複製的 token
   - `SHEET_ID`：訂房 Google Sheet 網址裡 `/d/` 和 `/edit` 中間那一長串
   - `WEBHOOK_KEY`：自己亂打一串英數字當暗號，例如 `27f-kizuna-8888`
   - （選填）`WEATHER_PLACE`、`WEATHER_LAT`、`WEATHER_LON`：天氣的地點名稱和經緯度，沒設定就是台北（`25.0330`、`121.5654`）。經緯度可以在 Google 地圖上對地點按右鍵複製
4. 右上「部署 → 新增部署作業」→ 類型選「網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
5. 按部署，第一次會跳出授權視窗：允許讀取試算表、連線到外部服務。複製「網頁應用程式網址」（結尾是 `/exec`）。
6. 用瀏覽器打開那個網址，看到「丼步喱・絆 LINE bot 醒著。」就是部署成功。

### 3. 把 webhook 接上

1. 回 Developers Console 的「Messaging API」分頁 → Webhook settings：
   - **Webhook URL**：部署網址加上 `?key=你的暗號`，例如 `https://script.google.com/macros/s/xxxx/exec?key=27f-kizuna-8888`
   - 打開 **Use webhook**
2. 回 Official Account Manager 的「設定 → 回應設定」：
   - 關掉「自動回應訊息」，不然官方帳號的罐頭訊息會跟 bot 一起回
   - 打開「Webhook」
3. 「設定 → 帳號設定」：允許「加入群組或多人聊天室」，才能拉進朋友的群組。

> Webhook settings 裡的「Verify」按鈕有時會因為 Apps Script 回應前會先轉址而顯示失敗，但實際傳訊息通常照樣會動。以「加好友傳一句『空房』有沒有回」為準。

### 4. 測試

用手機加官方帳號好友（Developers Console 的「Messaging API」分頁有 QR code），依序傳：

- `說明`：應該列出全部指令
- `空房`：接下來 30 天的房況
- `擲杯 今晚續攤嗎`：連擲三次，看三聖杯會不會蓋「定」
- `抽籤`
- `放假`、`月亮`、`分帳`、`油價`、`股 2330`、`排球`、`排球 戰績`、`狗`、`貓`

沒反應的話，到 bot 專案左側「執行作業」看紀錄。

想先看月曆卡片長什麼樣子：編輯器上方選 `printAvailabilityFlex` 按「執行」，把執行記錄裡的 JSON 貼到 [Flex Message Simulator](https://developers.line.biz/flex-simulator/)。

### 5. 圖文選單（選用，不用寫程式）

Official Account Manager →「主頁 → 圖文選單 → 建立」：

1. 版型選「大型」的 **3×2 六格**，圖片上傳 `richmenu.png`
2. 六格的動作（上排左到右 A、B、C，下排左到右 D、E、F）：
   - A 空房・查：類型「文字」，內容 `空房`
   - B 訂房・歸：類型「連結」，網址 `https://tingyu333.github.io/dongbuli4fun/`
   - C 天氣・觀：類型「文字」，內容 `天氣`
   - D 擲杯・問：類型「文字」，內容 `擲杯`
   - E 抽籤・運：類型「文字」，內容 `抽籤`
   - F 說明・閱：類型「文字」，內容 `說明`
3. 選單列顯示文字可以填「二十七樓」，設定成預設顯示，儲存。

> 已經建好舊的四格選單的話：直接編輯那個選單，換版型、換圖、照上面重設六格動作就好，不用刪掉重建。

## 指令

| 指令 | 回覆 |
| --- | --- |
| `空房`、`房況` | 一張月曆卡片：今晚有沒有人、從這週日起 5～6 週的月曆（有人住的晚上填枯茶色、今天加圈、過去變淡），底下「去訂房」按鈕。入住日到退房前一晚算有人，已取消不算。通知預覽顯示文字版 |
| `擲杯`、`擲筊`、`跋杯`（後面可以接問題） | 聖杯 1/2、笑杯 1/4、陰杯 1/4、1/88 立杯。同一個聊天室問同一個問題，連續三個聖杯蓋「定」；換問題或 6 小時沒擲就重算 |
| `抽籤`、`御神籤` | 一張籤紙卡片：吉用朱色大字、凶用墨色，下面兩行籤詩（跟網站首頁一樣），「再抽一支」按鈕。同一個聊天室不會連續抽到同一支 |
| `天氣`、`氣象` | 一張天氣卡片：現在溫度、體感、天氣，今天和明天的高低溫與降雨機率，加一句廢話建議。資料來自 [Open-Meteo](https://open-meteo.com/)（免費、不用金鑰），存 30 分鐘 |
| `訂房` | 網站連結 |
| `分帳`、`拆帳`、`算帳`、`記帳`、`誰欠誰`、`AA` | 一張卡片加「打開分帳」按鈕，打開老闆做的分帳 LIFF（網址在 `Code.gs` 的 `SPLIT_URL`）。bot 只給連結，不碰分帳的資料 |
| `油價`、`汽油`、`柴油` | 一張油價卡片：92、95、98、超級柴油的牌價。中油公告了下週價格（通常週日中午）就顯示「11/16（一）起 汽油漲 0.2」和新舊價格，還沒公告就比這週和上週。資料是[中油官方的牌價服務](https://vipmbr.cpc.com.tw/cpcstn/listpricewebservice.asmx)（不用金鑰），存 3 小時 |
| `股 2330`、`股 台積電`（`股價`、`股票` 也可以） | 一張股價卡片：收盤價、漲跌（漲朱色、跌綠色）、開高低、成交量。先查上市（[證交所 OpenAPI](https://openapi.twse.com.tw/)），找不到再查上櫃（[櫃買中心 OpenAPI](https://www.tpex.org.tw/openapi/)），都不用金鑰。只有最近一個交易日的收盤資料，不是即時。可以打代號或名稱（名稱只打一部分也行，「股 台積」→ 台積電）。群組裡查不到就不回，「股市今天好慘」不會被當成查股票 |
| `排球`（`TPVL` 也可以） | TPVL 台灣職業排球聯盟：下一場（日期、時間、對戰、場館）、再來兩場、最近一場比分，底下「看完整賽程」連到官網 |
| `排球 雲豹`（隊名打簡稱：連莊、天鷹、伊斯特、可利、台中、新竹…） | 那一隊接下來三場（主場／客場）和最近三場勝敗 |
| `排球 戰績`（或 `排名`、`積分`） | 五隊排名、勝敗、積分 |
| `排球 得分王`（`得分`、`得分榜`） | 得分前五名，附球隊、位置、每局平均。換成 `攔網`、`發球`、`攻擊`、`接發`、`防守`、`舉球`（`二傳`）就是其他排行，附每局或成功率／到位率 |
| `排球 球員 名字` | 一位球員的數據卡（出賽、總得分、每局、攻擊、攔網、發球、接發、防守、成功率，有資料的才列）和得分排名。名字打一部分也可以，同時符合好幾位會列出來讓你挑 |
| `排球 雲豹 球員`（`排球 台鋼球員` 不用空格也行） | 那一隊的得分前五名 |
| `狗`、`汪`、`狗狗`、`貓`、`喵`、`貓咪` | 一張隨機的狗或貓照片，加一句廢話（狗會說品種）。**要整句只有這個字**才算（「狗屎運」「貓咪好可愛」不會跳圖）。狗用 [dog.ceo](https://dog.ceo/dog-api/)，貓用 [The Cat API](https://thecatapi.com/)，抓不到再換 [cataas](https://cataas.com/)，都不用金鑰 |
| `說明`、`指令` | 全部指令，分成二十七樓、問神明、看天、過日子、沒有用五組 |
| 其他任何話、貼圖 | 一句廢話文學（「聽君一席話，如聽一席話」那種），同一個聊天室不會連續回同一句 |

### 天氣以外的看天、過日子指令

以前是隱藏指令，現在都寫進「說明」了。傳 `隱藏指令` 或 `彩蛋` 會回「已經沒有藏了」加上說明。

| 指令 | 回覆 | 資料從哪來 |
| --- | --- | --- |
| `空氣`、`紫外線`、`UV` | 空氣品質（AQI 和等級，用環境部的分級名稱）、PM2.5、現在和今天最高的紫外線。天氣卡片也會多一行空氣 | [Open-Meteo 空氣品質 API](https://open-meteo.com/en/docs/air-quality-api)，免費、不用金鑰，存 30 分鐘 |
| `月亮`、`月相`、`農曆` | 今晚的月相、農曆初幾、亮了幾成、下次滿月和新月 | 程式自己算，不用網路 |
| `節氣` | 現在是哪個節氣、第幾天，下一個節氣還有幾天，附一句廢話 | 程式自己算，不用網路 |
| `夕陽`、`日出`、`日落` | 日出、日落、魔幻時刻（日落到天黑）、白天多長，日落前倒數 | 程式自己算，地點跟天氣一樣用 `WEATHER_LAT`／`WEATHER_LON` |
| `放假`、`連假`、`假日` | 今天上不上班、下一個連假（三天以上）和倒數、之後兩段連假、六十天內的補班 | 行政院辦公日曆，用 [ruyut/TaiwanCalendar](https://github.com/ruyut/TaiwanCalendar) 整理好的 JSON（透過 jsDelivr），抓今年和明年，存 6 小時 |

- 月相、節氣、日出日落用 Meeus《Astronomical Algorithms》的簡化公式。2026、2027 兩年跟政府行事曆的農曆日期（730 天）和節氣（48 個）全部對得上，日出日落跟氣象署差一兩分鐘。
- 部署後可以在編輯器選 `testHiddenSources` 按「執行」，執行記錄會印出排球賽程、戰績、球員（得分、攔網、舉球）、股價（台積電、環球晶）、狗、貓、油價、空氣、行事曆有沒有抓到。Apps Script 是從 Google 在國外的機房連線，某個來源抓不到的話，那個指令會回一句文字，其他照常。
- 明年的行事曆通常年中才公布，還沒公布前「放假」只看得到今年的。
- **排球沒有公開 API**：資料是從 [tpvl.tw/matches](https://tpvl.tw/matches)、[/standings](https://tpvl.tw/standings) 網頁裡的 Next.js 資料（`self.__next_f.push`）挖出來的，解析方式參考 [ichendong/tpvl-skill](https://github.com/ichendong/tpvl-skill)（MIT）。**官網改版就可能壞**，壞了會回「讀不到」，執行記錄會寫「解析不到」。這時候先在編輯器跑 `debugTpvlPlayers` 和 `debugTpvlLinks`，把執行記錄交給改程式的人（它們會印出頁面實際的欄位和連結）。賽程、戰績各存 30 分鐘，球員數據（[/stats/players](https://tpvl.tw/stats/players)，每種排行一頁）存 1 小時。

- 只認訊息**開頭**的關鍵字。
- **一對一**：不是指令也會回廢話，傳貼圖也回。
- **群組**：只有 **@bot** 才回廢話，平常聊天不會被插話；「@bot 空房」也能當指令用。
- 加好友、被拉進群組時會打招呼。

## 改程式的規則

- **只讀**：要寫入的事（訂房、改狀態、取消）一律回網站連結，不在 bot 裡做。Apps Script 讀不到 `X-Line-Signature`，沒辦法確認請求真的來自 LINE，bot 能寫入的話，誰都能透過它寫入。
- **只回覆**：不用 Push API。要主動通知（例如新訂房）會用到每月 200 則的額度，而且訂房是公開動作，被洗版就會燒光；真的要做，先加每日上限。
- **不回個資**：名字、電話、Email 都不回。
- **廢話台詞**在 `Code.gs` 的 `NONSENSE_LINES`（文字）和 `STICKER_LINES`（貼圖），直接加句子就好，改完重新部署。
- **台詞跟網站同步**：擲杯台詞在 `jiaobei.html` 的 `RESULTS`，御神籤在 `index.html` 的 `FORTUNES`。改了網站的台詞，記得也改 `Code.gs`，再重新部署。
