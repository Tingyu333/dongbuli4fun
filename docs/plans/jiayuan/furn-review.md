## 折衷清單（第一輪）

### 一定要改
- **四柱床**（三位都提）：黑色款像鐵籠、只有框沒有布。柱子加粗、左亮右暗、柱頂圓頭；四根柱子都綁布簾、頂框一圈布幔（被子色亮一點）；床尾一條橫毯；床頭板加高。
- **三門大衣櫃**（妹妹、設計師）：說好「中間是鏡子」卻沒畫。中間那扇改淺藍灰鏡面＋兩條斜白反光、木色鏡框。
- **立燈**（美術指導、設計師；妹妹說可以更好）：燈罩是一片平板像路牌，又高到快碰天花板像路燈。燈罩改梯形圓筒（亮頂面、正面、暗右側、下緣亮線）、整支降到約 32 顆。
- **玻璃茶几**（三位都提）：像雙人床、黑色款像黑地毯。玻璃四邊亮邊＋斜反光、下層板往內縮讓地板露出、腳看得到；紅方塊換成一本書或一小盆花；高度降到跟沙發坐面差不多。
- **四人方桌、六人長桌、靠背椅**（設計師；美術指導說椅子跟桌子同色糊在一起）：椅背太高又是實心板，把餐桌圍成箱子。椅背降到 18 顆、改兩根直柱＋橫條的鏤空；椅子比桌子暗一階。長桌中間的橘方塊改圓花瓶插花。
- **整面書牆**（美術指導、設計師；妹妹最想買）：格子背板接近黑 → 本色暗三成；書高一倍像彩色長條 → 層數變多、書矮一點高低不一、幾格空位或橫躺的一疊。
- **電腦桌**（美術指導；妹妹、設計師說不用動）：折衷只補細節，不改結構：螢幕亮邊框和支架、鍵盤看得出一顆顆鍵。
- **金框大展示櫃**（三位都提）：一個黃色箱子像候車亭。框改深一點的金＋左上亮金邊、玻璃更透＋斜反光、背板深色絨布（藏品比較跳）。空櫃要不要擺裝飾 → 問使用者。

### 可以更好
- **單人床、雙人床**：被子是一塊板 → 兩側、床尾垂下來，靠枕頭那頭摺一截，枕頭鼓一點；床墊白側邊；淺色款小圖底下暗一點。
- **床頭櫃**：抽屜只有一排點 → 抽屜縫＋圓把手；檯燈梯形燈罩。
- **弧形落地燈**：像釣竿、燈罩像吐司 → 拿掉吊線，碗形燈罩掛在彎桿尾巴，彎桿亮邊、底座頂面。
- **雙門衣櫃**：門縫明顯一點、門框線、底下小短腳。
- **矮書櫃**：書歪一兩本。
- **玻璃小櫃**：像空木框或魚缸 → 玻璃兩條斜反光（空櫃的事同金框展示櫃）。
- **木書桌**：抽屜盒浮在半空 → 改成落地的三層抽屜櫃；桌上一本打開的筆記本。
- **木椅凳**：像小茶几、太高 → 坐面降到 8 顆、加一塊坐墊。
- **木茶几**：比沙發坐面高 → 降到 7.5 顆；紅方塊像坐墊 → 茶壺＋兩個杯子；白色款右側暗一點。
- **整批**：家具全部平塗，放在有木紋的地板上像塑膠積木 → 大面木頭加 2～3 條淡木紋、頂面前緣 1 格亮邊（跟家門口屋簷、欄杆一樣）。白、米色款的商店小圖跟底色太近 → 加一塊小地影。
- **晚上**（房間的畫法）：光暈是平滑漸層、漏到房間外 → 三圈硬邊色階、裁在房間裡；晚上地板最暗接近黑 → 收在 `#3d4246` 那組附近；西牆左端、東牆右端內側一條暗縫 → 補成牆的暗面。

### 不用動
- 雙人床的比例、電腦桌的結構、靠背椅的坐墊顏色、四人方桌和六人長桌的擺法（桌子＋椅子）、矮書櫃、木書桌的高度。

### 要使用者決定
- **黑色款的色碼**（美術指導）：四柱床、三門大衣櫃、矮書櫃、整面書牆、玻璃小櫃、電腦桌、木椅凳、靠背椅、六人長桌、玻璃茶几的「黑」實際是 `#2b2b2e`～`#373532`，比規矩最暗的 `#30353a` 還暗，跟家門口的黑（`#3d4246` 那組）不像同一套。建議改成 `#3d4246`（正面）／`#30353a`（右側）／再亮一階（頂面）。顏色的名字不變。
- **空的展示櫃**（妹妹要擺東西，設計師說擺了藏品就清楚）：空櫃要不要擺淡淡的裝飾。
- **門寬**（設計師，不在這批範圍）：照家具的比例，一格約 50 公分，門 1.2 格只有 60 公分、比單人床還窄；之前使用者定的，要不要改另外說。

## 結果（2026-11-27）

- 第一輪：使用者「整批照建議改」；黑色款改成 `#3d4246` 那組（名字不變）；空的展示櫃就空著。
- 第二輪：白天大多可以收藏；新問題是晚上的光暈改成三圈硬邊後像標靶、泡泡（妹妹、設計師），美術指導另外抓到兩張餐桌畫的順序錯、幾處比 `#30353a` 暗、牆端內側暗縫。可以更好：四柱床布簾像柱子、椅凳坐墊像豆腐、抽屜縫斷成一排點、弧形落地燈小圖的影子。
- 第三輪：妹妹、設計師可以收藏；美術指導：最暗下限要照亮度算、地上的光要在家具之前畫、燈罩被光蓋掉。改成晚上兩層（房間先調暗＋地上牆上的光，家具另一層調暗再貼上來，最後燈泡）。
- 第四輪：美術指導可以收藏（黑色電腦桌晚上調暗後又掉到下限以下 → 調暗後再過一次下限）。使用者點頭。
