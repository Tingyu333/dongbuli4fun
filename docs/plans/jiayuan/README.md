# 家園・築（企劃中）

許願池有人許願「增加購買不動產／車子／飛機／遊艇／火箭的選項」。使用者 2026-11-21 想做成「收納這些東西的地方，像是我的家園」：裡面是像素風、看得到自己的藏品，買東西前要先解鎖設施（例如買飛機前要先蓋停機坪）。

## 已經定的

- **畫風：精緻像素風**（2026-11-21 使用者說「我很喜歡，幫我記錄這個風格」）。樣張：`style-mockup.png`，畫法：`style-mockup.html`（canvas 原始碼，之後照這個寫）。
- **先做正上方（俯瞰小島），之後再追加斜四十五度**（樣張裡的「貳」）。所以島要**用格子排**（例如 12 × 12，每樣東西佔幾格），正上方照樣畫圓滑的海岸線；每樣東西的畫法分開寫（正上方一套、之後斜看一套），點擊、動畫都照格子算，之後追加斜看不用改資料和後端。
- **跟網站侘寂風的反差是故意的**：家園是網站裡「另一個世界」的角落（使用者確認過）。
- **遊戲幣永遠不碰真錢**：家園裡的東西只能用遊戲幣買，不能換成任何真的東西，頁尾照樣放那句聲明。

## 精緻像素風的規矩（照樣張）

- **解析度**：畫布約 240 × 200 顆像素，手機上放大成約 360px 寬（一顆約 1.5px，上一版粗像素是 2.8px）；CSS `image-rendering: pixelated`。
- **硬邊**：不用 canvas 內建的反鋸齒路徑，多邊形用自己寫的掃描線填色（`poly()`），圓用逐點判斷（`circ()`、`ell()`），每一顆都是整數座標。
- **光從左上來**：每樣東西三個色階（亮、本色、暗），亮面在左上、暗邊在右下；**影子往右下偏 3～4 顆**，半透明 `rgba(30,40,30,.22)`。
- **不用黑色描邊**：輪廓用同色系的暗色（例如紅瓦用 `#7a241d`）。
- **紋理靠雜點**：沙灘、草地、水泥每一顆用固定亂數 `hash(x, y)` 挑 2～4 個相近的顏色；海照離島的距離分深淺，交界用棋盤格混色（dither）；島邊一圈白浪花，海上零星浪點。
- **色票**（樣張裡的 `K`）：海 `#4f7d8f`／`#6b97a6`／`#7ea9b5`／淺灘 `#9cc5c8`／浪 `#e3efed`；沙 `#e6d3a3`／`#d8c18b`／`#efe0b8`；草 `#97ad6f`／`#86a061`／`#a6bb7c`／`#738d51`；樹 `#5d7c43`／`#4a6634`／`#7a9a55`／亮 `#9cb96f`；紅瓦 `#b33a2f`／亮 `#cf5a46`／暗 `#8f2c23`；牆 `#efe4cf`；窗燈 `#f6cd72`；水泥 `#c4beb3`／`#aea79b`；車紅 `#c0392b`；機身 `#eef0ef`；木頭 `#9a6a40`／`#7c5230`；還沒解鎖的灰 `#d7d0c4`／`#c2b9aa`、鎖 `#8e8070`。朱色 `#b33a2f` 跟網站同一個。
- **還沒解鎖**：那一塊地畫成灰色虛線圓（或方）＋一把鎖，看得到位置但買不了。
- **細節的程度**（樣張）：房子一片片瓦、屋脊、煙囪、門口小屋簷和花圃；車有擋風玻璃、車燈、輪胎；飛機有引擎、窗、紅色尾翼、翼尖紅綠燈、地上影子；遊艇有木甲板、船艙、船尾浪；碼頭一根根木板和木樁。
- 之後要做：會動（車開、飛機起飛、火箭發射、浪）、夜裡換夜景（窗戶亮燈），跟網站的夜間模式一起換。

## 擴充性（使用者 2026-11-21 要的：之後要能做到屋內裝潢，細到衣櫃裡的衣服、一個設施能放幾個）

資料一開始就照「一層包一層」記，第一版只做到設施也沒關係，之後加屋內、家具、衣服不用搬資料：

```
島（可以不只一座；每座島有自己的格子大小，可以擴張）
└ 設施（家、車庫、碼頭、停機坪、發射台、庭院…，佔幾格、放在哪一格）
   ├ 等級（家：帳篷 → … → 海景別墅；車庫：一個車位 → 三個車位）
   └ 房間（家的等級決定有幾間：帳篷 1 角落、木屋 1、平房 2、洋房 4、別墅 6）
      └ 家具／擺設（放在房間裡的小格子上：床、桌、衣櫃、書櫃…）
         └ 收納的東西（衣櫃裡的衣服、書櫃裡的書；車庫裡的車也是這一層）
```

- **目錄**（寫在網頁裡，大家一樣）：每一種東西一筆：`key`、名字、種類、價錢、佔幾格、要先有什麼（例如飛機要先有停機坪、火箭要先有發射台）、**容量**（能裝幾件、能裝哪一種，例如衣櫃 12 件衣服、車庫一級 1 個車位）、**上限**（一個人最多幾個，例如車庫最多 2 座、火箭 1 台）。
- **玩家有的**（存在後端，每個人一份）：一件一筆，`id`（這一件自己的編號）、`key`（目錄裡哪一種）、**放在哪**（`in`：裝在哪一件裡面的 `id`；`at`：在那裡面的哪一格）、狀態（例如顏色、取的名字）。例：
  ```json
  [
    { "id": "i1", "key": "island.home", "size": [12, 12], "land": "…（哪幾格是陸地，擴張就多幾格）" },
    { "id": "h1", "key": "house", "lv": 3, "in": "i1", "at": [1, 1] },
    { "id": "r1", "key": "room.bed", "in": "h1" },
    { "id": "f1", "key": "furn.wardrobe", "in": "r1", "at": [0, 2] },
    { "id": "c1", "key": "cloth.yukata", "in": "f1", "color": "indigo" },
    { "id": "g1", "key": "garage", "lv": 1, "in": "i1", "at": [1, 6] },
    { "id": "v1", "key": "car.sports", "in": "g1" }
  ]
  ```
  這樣「一個設施放幾個」就是看容量、數 `in` 是它的有幾件；衣服、書、車都是同一種寫法，之後加新種類只要在目錄加一筆。
- **屋內畫面**：點房子進屋內，一樣是正上方的精緻像素（把屋頂拿掉看房間），兩層以上可以切樓層。家具放在房間的小格子上。
- **衣服**：放衣櫃；平房以上的曬衣繩隨機晾幾件你有的衣服。之後也可能「穿」在頭像或島上的小人身上（還沒想）。
- **後端存法**：不能塞進錢包的店面升級（那裡只能存 0～10 級），要另外存一份清單。試算表一格最多五萬字，所以要定一個人最多幾件（例如 500 件），買東西、擺東西都在後端檢查錢夠不夠、容量夠不夠、前面的解鎖有沒有。

## 使用者想到的（2026-11-21，先記下來，還沒排進第一版）

1. **島可以擴張，甚至有第二座島**
   - 擴張：島是一格一格的陸地，「填海造地」就是多買幾格陸地（每座島記哪幾格是陸地），海岸線照陸地重新畫成圓滑的。格子本身也可以變大（12 × 12 → 16 × 16…），所以島的大小不要寫死。
   - 第二座島：資料最上層本來就是「島」，多一座島就是多一筆。怎麼去另一座島可以有梗：要先有碼頭（坐船）或停機坪（坐飛機）才去得了；畫面上方切換「本島／二號島」。
   - 每座島可以有自己的主題（例如沙灘島、雪島、火山島），能蓋的特殊設施不一樣。
2. **所有等級跟上限都保留擴充空間**
   - 等級、容量、上限、價錢都寫在目錄裡（陣列，有幾級就幾筆），**程式不寫死最高幾級**；加一級就是目錄多一筆，舊的存檔照樣能讀。
   - 跟店面升級不一樣：店面升級後端只收 0～10 級，家園另外存，後端照目錄檢查（目錄要前後端各一份，或後端放一份給網頁讀）。
   - 一個人最多幾件、一座島最多幾個設施、最多幾座島，都是目錄裡的數字，之後要放寬只改數字。
3. **特殊設施**（可能會加，先列想得到的）
   - 跟網站其他遊戲連動的：菜園（菜園・拔）、礦坑入口（礦坑・挖，浣熊大王住這）、小吳鴨的巢（疊・巢）、甜點店分店（甜點・轉）、碼頭停長蘿貨運的船（貨運・航）、坐洗部分店。
   - 有梗的：神社＋鳥居（功德・添的分社）、燈塔（晚上會轉）、溫泉、觀星台（火箭發射留下的星星看得最清楚）、27 樓大樓（一層一層往上蓋，最上面是「絆」房，但永遠不賣）。
   - 特殊設施可以有特別的解鎖條件，不只是錢：例如礦坑十關破關才能蓋礦坑入口、功德到某一階才能蓋神社。
4. **移動設施**（使用者：不知道好不好做，可以先不做）
   - 做法其實不難：每樣東西本來就記「放在哪一格」（`at`），移動就是改這個；要檢查的只有「不能疊在別的東西上、不能超出陸地、海邊的東西（碼頭、別墅）要靠海」。
   - 難的是手機上的操作（長按拿起、拖曳、放下，畫面還要能捲動），所以第一版先不做：每種設施有建議的位置，蓋的時候放在那裡。但**資料一開始就記位置，不要寫死「車庫一定在左下」**，之後要開放移動就不用改存檔。
