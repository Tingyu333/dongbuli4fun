# 家具審稿・後 20 件（2026-11-27）

審稿員：像素美術指導、文組妹妹、室內設計師。總表 `furn2-review-1x.png`（手機實際大小）、`furn2-review-3x.png`（放大 3 倍）。拍法跟前 20 件一樣（平房客廳擺兩件，下面一排商店小圖；電視多一張晚上）。前 20 件的全域改動（亮邊、木紋、地影、最暗下限、晚上兩層的光）已經套在這批上。

## 折衷清單（第一輪）

整體（三位都提）：沙發、電視、地毯跟前 20 件大致同一套；植物、廚房、掛畫粗一截（一兩個色階、方塊盆、一大塊黑、平塗的畫），還不像同一套。

### 一定要改
- **高背扶手椅**（三位都提）：一層層台階像積木、耳朵浮在半空。改成沿後緣一片高椅背（約 21 顆，扶手的兩倍）、兩側翼板從扶手一路連到椅背頂（上窄下寬）、扶手圓一點、坐墊一塊有縫、前面露出木頭小腳。
- **布單人椅**（設計師；美術指導、妹妹說可以更好）：扶手太寬坐不下人、米色款糊在牆上。扶手變窄、椅背比扶手高、木頭小腳、底下一條暗邊。
- **L 型沙發**（美術指導、妹妹）：影子是整個 5×4 的大菱形，L 缺角的空地也有 → 影子照 L 形分兩塊；坐墊之間的縫深一點、中間鼓一點、多兩三顆抱枕（換色）。
- **小電視櫃**（設計師、美術指導）：電視太高、太方、像映像管 → 薄型寬螢幕、降低、加小腳座；旁邊的白方塊換成看得出來的東西。
- **大電視＋音響**（三位都提）：喇叭像兩根黑柱子、又放在櫃子上 → 落地喇叭放在兩端地上，正面一大一小兩個圓；電視降一點。
- **電視晚上**（美術指導）：螢幕中間一顆圓亮點像燈泡 → 整片螢幕均勻亮、地上的光是螢幕正前方一塊扁扁的光。
- **圓地毯的商店小圖**（美術指導、妹妹）：三顆素色橢圓 → 跟屋內一樣的同心圈和邊。
- **小盆栽**（美術指導；設計師說盆太大）：葉子是橫長條、盆是方塊 → 尖橢圓葉從中心往外長、盆上寬下窄有盆緣露一點土、盆小一點。
- **龜背芋**（三位都提）：看不出龜背芋 → 4～5 片大心形葉、葉緣裂口和小洞、葉柄從盆裡長出來。
- **流理台**（美術指導；設計師說太高）：檯面上的白方塊看不出是什麼 → 砧板、調味罐；檯面降到約 90 公分、檯面板薄一點（水槽、瓦斯爐一起，三件等高）。
- **水槽**（美術指導、妹妹）：看不到凹下去的槽 → 挖一個槽（後緣內側暗、前緣內側亮、槽底反光）、彎的銀色水龍頭、旁邊一瓶洗碗精。
- **瓦斯爐**（美術指導；妹妹說可以更好）：烤箱門一整塊黑 → 橫門把、玻璃反光、一排旋鈕；爐頭畫成圓圈加爐架、放一個小鍋子。
- **單門冰箱**（三位都提）：黑款一根黑柱子、把手太淡；太高太瘦。降到約 1.5 公尺、直的長把手（亮一階＋亮點）、頂面亮邊。**上下兩門還是一扇門 → 問使用者**（名字是「單門」，設計師說畫一扇；妹妹、美術指導說畫上下兩門的縫）。
- **風景畫**（美術指導；妹妹、設計師說框小、太方）：天空、山、草各一色、太陽是方塊 → 天空漸層、遠山近丘兩層有亮暗面、圓太陽、三階畫框；改成橫幅、大一點、中心約 1.55 公尺；商店小圖畫一樣的內容。
- **浣熊大王肖像**（三位都提）：太小、浣熊圖是糊的又沒跟著牆斜、商店小圖只有深藍底 → 畫框大一點（跟風景畫差不多）、金框雕花角，浣熊跟著牆斜切、硬邊像素，小圖也畫上浣熊。

### 可以更好
- **沙發坐面**（設計師）：6.5 顆比茶几還低 → 坐墊到 7.5，扶手、椅背跟著上移。
- **雙人布沙發、三人皮沙發**（三位）：椅背跟扶手一樣高像淺盤 → 椅背加高、兩個靠背墊；坐墊鼓一點、縫看得出來。皮沙發的光澤改成坐墊左上一顆亮線（現在的白點像水滴）。
- **抱枕**（美術指導）：五款沙發都放同一顆黃抱枕 → 換顏色、換形狀。
- **長方地毯、走道長毯**（三位）：中間一排白短線像停車場、跑道 → 內框＋中央菱形紋、短邊流蘇。
- **小橘子樹**（美術指導；妹妹最想買）：樹冠三個色階、葉叢凹凸；盆照小盆栽改成陶盆。
- **雙門大冰箱**：降到約 1.8 公尺、把手亮一點、頂面亮邊。

### 不用動
- 圓地毯（屋內）、小盆栽的紅陶色、瓦斯爐的整體形狀。

### 要使用者決定
- **這批寫死的深色**（美術指導）：電視機身、喇叭、黑電視櫃、黑冰箱、瓦斯爐面板現在用 `#232326`、`#2b2b2e`、`#3a3a3d`、`#2e2d2c`、`#3d3b38`，被最暗下限夾成一整片平塗，冷暖又混在一起，跟前 20 件的黑不像同一個黑。建議統一走 `#3d4246` 那組（暗面不低於 `#30353a`、頂面約 `#4f555a`、把手約 `#6a7075`），螢幕玻璃保留深藍灰。
- **單門冰箱**：一扇門，還是上下兩門。

## 結果（2026-11-27）

- 第一輪：使用者「整批照建議改」；這批寫死的深色統一走 `#3d4246` 那組；單門冰箱畫一扇門。
- 第二輪：妹妹、設計師可以收藏（小意見：龜背芋像棕櫚、白冰箱把手太淡、高背椅抱枕像面紙盒、米色單人椅底邊、小電視櫃門縫）；美術指導：沙發扶手、坐墊邊在斜線上變一排小牙（不到一顆高的薄盒子）、抱枕被靠背墊蓋掉、橘子樹木桶像陀螺、水槽一片雜點、冰箱把手和門縫不到一顆寬會不見、風景畫右框漏掉、浣熊肖像跟著牆斜切後五官散掉。
- 第三輪：美術指導 10 件可以收藏（橘子樹鐵箍改連續的線）；浣熊肖像改成「兩顆一欄」後妹妹說像條碼 → 折衷：一顆一欄 8 × 11、畫的內容兩欄一組跟著牆往下移（`paintWall`），一定有尖耳朵、面罩裡兩顆白眼睛、大黑鼻子，皇冠小一點不貼框，下面一整條紅披風。妹妹確認可以收藏，使用者點頭。
