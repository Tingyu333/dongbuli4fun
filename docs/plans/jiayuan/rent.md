# 小島收租（企劃，還沒做）

2026-11-22 使用者想要「可以掛機賺錢的管道」，選了小島收租。**要跟接後端一起做**（租金用後端的時鐘算，跟儲蓄險一樣，手機調時間沒用）。

## 使用者定的
- 會員中心多一欄「小島收租」（`earned` 另外一類），**不算打工・榜**。
- **不算進身價**（身價只算島上的東西）。
- 金庫最多存 **12 小時**，滿了就不再加。
- 數字先照下面這份給使用者看（2026-11-22），還沒定案。

## 玩法
- 蓋好的設施自己有客人：家＝民宿房租、車庫＝代客停車、碼頭＝遊艇出租、停機坪＝觀光飛行、發射台＝太空旅遊。錢存進金庫。
- 家的上面浮一個小錢袋寫金額，點了收租、錢飛進錢包，跳一張旅客留言的紙條；滿了錢袋寫「滿了」。
- 停在位子上的車船飛機，每小時多賺牠買價的萬分之 0.5；停在倉庫的、送的（火箭、熱氣球、飛艇）不算。
- 島上開出去的車船飛機頭上冒「+$」只是好看，錢照每小時算。
- 升級卡片多寫「每小時多賺 $X・回本約 N 天」。
- 後端：每個人記上次結算時間和還沒收的錢；蓋東西、停車、收租之前先把到現在的租金照舊的設施結算進金庫（上限 12 小時份），再改設施。
