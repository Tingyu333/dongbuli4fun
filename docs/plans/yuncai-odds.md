# 運動・押改固定賠率（企劃，還沒做）

2026-11-22 使用者問「一個人押也有機會賺錢」要怎麼調，選了「固定賠率（照戰績算倍數）」，2026-11-23 先試算。

## 算法（試算版）
1. 兩隊這季一場的勝率（例行賽打完的），用 log5 算主隊贏這場的機率：`a(1−b) ÷ (a(1−b) + b(1−a))`。
2. 往五五拉一點（`0.5 + (p − 0.5) × 0.75`，避免太篤定）、主場 +2%，夾在 8%～92%。
3. 反推「單局勝率」s（五局三勝：贏一場 = s³(1 + 3q + 6q²)，q = 1 − s），再算六種比分：3:0 = s³、3:1 = 3s³q、3:2 = 6s³q²，客隊反過來。
4. 倍數 = 0.9 ÷ 機率（系統抽一成），往下取整：誰贏取到 0.05、比分取到 0.1；最少 ×1.05、最多 ×30。
5. 季初場數少：之後用「這季戰績＋上季戰績當底」混合（上季算 10 場份）。

## 試算（用 2025-26 例行賽勝率：連莊 90.5%、天鷹 61.9%、伊斯特 33.3%、雲豹 14.3%）
- 連莊（主）vs 天鷹：主贏 79% ×1.10、客贏 21% ×4.20；3:0 ×3.0、3:1 ×3.0、3:2 ×4.5、0:3 ×23.6、1:3 ×11.8、2:3 ×8.9
- 連莊（主）vs 雲豹：主贏 88% ×1.05、客贏 12% ×7.60；3:0 ×2.2、3:1 ×2.8、3:2 ×5.4、0:3 ×30、1:3 ×22.3、2:3 ×15.1
- 天鷹（主）vs 伊斯特：主贏 72% ×1.25、客贏 28% ×3.15；3:0 ×3.7、3:1 ×3.3、3:2 ×4.3、0:3 ×16.5、1:3 ×8.8、2:3 ×7.1
- 伊斯特（主）vs 雲豹：主贏 71% ×1.25、客贏 29% ×3.05；3:0 ×3.8、3:1 ×3.3、3:2 ×4.3、0:3 ×15.6、1:3 ×8.5、2:3 ×6.9
- 模擬 10 萬場：押強隊拿回 88.8%、押弱隊 89.1%、押最可能的比分 88.4%、押最冷的比分 82.3%、兩邊都押 88.9%（每一種押法長期都小輸，沒有穩賺的押法）。

## 還要定
- 抽幾成（試算是一成）。
- 冷門倍數高，50 萬押 ×30 會拿回 1,500 萬：要不要加「一注最多拿回多少」。
- 已經押、還沒開獎的注照舊的彩池規則派彩。
