## 樣張裡的五個畫面
1. **辦公室**：車庫創業的像素畫面，三張桌子坐三個員工（茱莉鴨睡著了冒 Z）；下面「進行中」：做完的案子按「收款」，做到一半的有進度條和倒數。
2. **委託板**：軟木板上釘四張紙條，從 30 秒到 4 小時都有，寫委託人（網站角色）、要幾個人、要求（細心 3 以上、研究 4 以上、要先談：談判 5），有「急件」「大案」章；幾分鐘貼一批新的；同時能做的件數有上限。
3. **派人**：員工四種能力（速度、細心、研究、談判）＋個性一句話；在忙的變灰；還沒請的可以花錢請；下面算預計多久、做得好的機率。
4. **突發狀況**：做到一半跳紙條（例：茱莉鴨又睡著了），三個選項，各有代價；幾秒沒選就自己選第一個。
5. **公司升級**：車庫創業 → 小辦公室 → 整層樓 → 二十七樓整層 → 自己的大樓 → 掛牌上市（變成股市・炒的一檔股票，你是執行長、可以發公告）。

## 員工（2026-11-24 使用者丟想法，其餘「都照建議」）
- 員工用**聘用**的，聘到的也可以**解雇**。應徵的人**一次隨機三位**，**刷新要錢**（跟著公司階段變貴：車庫 $500 … 上市前 $5 萬），另外**每隔幾小時免費自己換一批**。
- **一般員工**：網站沒出現過的小動物（鴿子、麻雀、松鼠、倉鼠、兔子、刺蝟、青蛙、烏龜），顏色隨機，名字像「鴿子・阿財」。四種能力（速度、細心、研究、談判）每項 1～4 顆，加起來約 6～10 顆。
- **9 位特殊角色**：加起來 14～17 顆、有一項 5 顆，另外一個專屬本事；費用比較高。每格約 5% 出現，已經請到的不會再出現，一個人每個角色只能請一次。
  - 茱莉鴨 細心 5：品質最好、多拿錢，但會睡著／小吳鴨 研究 5：研究案特別快／浣熊大王 談判 5：能接「要先談」的大案，偶爾順手多摸一點錢／青江菜船長 速度 5：帶隊，同組都變快／店貓：招財，結案多拿一點，但常常不在位子上／蘋果鴨：人緣好，委託板多一張／鼴鼠：挖到隱藏高價案／坐洗部的狗：忠心，薪水打折／雞塊：什麼都 3 顆，特殊角色裡最便宜。
- **錢**：聘用付一筆**簽約金**（特殊角色貴很多）；**結案時扣薪水**，照案子花多久和員工等級算，結案單寫「案子 − 薪水 ＝ 入帳」；**做砸了薪水照扣一半**。
- **解雇**：做案子中的不能解雇；簽約金不退；特殊角色解雇後回到應徵名單。
- **人數上限**跟著公司階段：3／5／8／12／20 人。
- **升級**：做越多案子升級，能力加一點、薪水也漲一點。
- 樣張 `staff.png`（`staff.html`）：應徵三位（特別人選是金框）、刷新 $500／幾小時後免費換、員工名冊和解雇確認、結案單（案子 − 薪水 ＝ 入帳、升級）、做砸了（只付三成、薪水扣一半）、八種一般員工的樣子。
