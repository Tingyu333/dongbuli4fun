# admin.html

admin・後台（2026-11-20 使用者要的「另一個後台，叫 admin 後台」）：管玩家和遊戲，跟訂房的「預約・一覽」（`admin_dashboard.html`）分開。預約後台最下面有一行連結過來。不在導覽列，`noindex`。載 `theme.css`／`theme.js`、`avatar.js`；`API_URL` 寫死在頁內（跟其他頁同一個網址）。

**登入用另一組密碼**（使用者選的）：指令碼屬性 `GAME_ADMIN_PASSWORD`（沒設定會說「還沒設定」），`gameAdminLogin` 發的通行證存 localStorage `gameAdminToken`（6 小時，跟預約後台的 `adminToken` 互不通用：預約後台的通行證打 `ga*` 回 `unauthorized`，反過來也是）。通行證過期就回登入畫面、寫「通行證過期了」。登入錯十次鎖十分鐘（`gaLoginFails`，跟預約後台分開算）。

**四個分頁**（2026-11-20c 加了道具庫）：
- **玩家**（`gaPlayers`）：每人一張卡：頭像（指定頭像優先）、暱稱（有暱稱的話後面小字寫 LINE 名字）、上線多久前（`Players` H 欄）、加入日期、身上還有效的道具（朱框小章）、錢包、賺過（`earned` 各來源加總）、花過、店面升級總等級、升級花多少、功德（捐＋點燈）。可以搜名字、排序（錢最多／賺最多／花最多／最近上線／最新加入）。「發道具」直接跳到道具分頁、選好那個人。**不給 line_id**，用 `key`（line_id 的 HMAC 前 12 碼）認人。
- **道具**（`gaPerkGrant`／`gaPerkRevoke`）：發專屬道具：給誰、什麼道具（**從道具庫挑**，停用的不能選；選單寫「名字（效果）」）、期限（永久／7／30／90 天／一年）、備註（只有後台看得到，60 字）；發之前跳確認。下面列「還有效的」（可以收回）和「收回、過期的」（最近 50 筆）。`PERK_TYPES` 的 `live: false` 是只有架子、效果還沒做（畫面上寫「效果還沒做」）；`shop60` 從 2026-11-20b 起 `live: true`，效果見下面。同一個人同一種道具還有效時不能重發。
- **道具庫**（`gaLibSave`／`gaLibRetire`，使用者 2026-11-20 要的「可以為道具命名」）：道具的名字主人自己取（最多 12 字），每個道具掛一種**效果**（`PERK_TYPES`，寫在程式裡，現在只有 `shop60` 六折）；同一種效果可以有很多個名字。可以附「一句話」（最多 30 字，拿到的人在商店的朱印旁邊看得到）。表單下面有預覽，長得跟玩家商店裡那條一樣。每個道具一張卡：名字、效果、那句話、有效幾個、發過幾次，按鈕「發這個」（跳到道具分頁、選好）、「改」（改名字和那句話；**效果建了就不能改**，發出去的會跟著變）、「停用／恢復」（停用＝不能再發，已經發出去的照樣有效，要收回去道具分頁）。改名後拿到的人下次同步就看到新名字。名字不能跟其他還在用的撞名；停用的可以撞，但恢復前要先改名。第一次打開時道具庫自動放進原本的「全店六折」（id 就叫 `shop60`，以前發的直接對得上）。
- **經濟**（`gaEcon`，只讀 `Players`，很快）：玩家數、24 小時／7 天內上線、全站的錢和中位數、第一名是中位數幾倍（超過 3 倍要注意）、大家賺過／花掉、店面升級花、功德；「錢從哪裡來」每個來源的總額、佔比、幾個人、幾次（長條）；最有錢的五個；「要看一下的」：錢包快到一兆上限、錢是中位數 10 倍以上（而且超過 10 萬）、某個遊戲一場賺的是大家中位數 4 倍以上（至少 3 個人有紀錄、超過 $2 萬）。**真人工資**（`gaWage`）：按「算一次」才算（讀全部紀錄分頁，比較慢），最近 7／30 天或全部，跟 `econReport()` 同一套算法（`econCompute()`），但只回傳、不寫「對帳」分頁。

**「全店六折」（`shop60`，2026-11-20b 做好，使用者定的）**：
- 只算**打工店的店面升級**（坐洗、菜園、蹭網、早餐、貨運、甜點、疊巢，礦坑也算；後端 `PERK_TYPES` 的說明 2026-11-20d 改成「八家」）；刮刮樂、功德、股市、保險照原價。
- **不公開**：排行榜、會員中心、別人的畫面都沒有標記；只有本人在商店裡看到原價劃掉、六折價、最上面一個朱印「專屬・六折」。**拿到的人是誰不寫進程式、說明書、版本紀錄**（repo 是公開的）。
- 到期或收回後恢復原價，已經買的升級留著。要登入才有（訪客、登出就是原價）。
- 花錢照實際付的記（`spent`、店面 `shop.spent` 都是六折後的），花錢榜也是。使用者還沒說要不要改成照原價算。
- 只能主人在這裡送，不能拿真錢換（遊戲幣不碰真錢）。
- 怎麼接：後端 `walletView()` 多回 `perks`（`perksFor(line_id)`，只給本人、只有 `live` 且沒過期的，cache `perks:v1` 10 分鐘，發／收回時清掉）；前端見 `docs/wallet.md`「專屬道具」。

**之後可能加的道具**：使用者想再加幾種，還沒選。

**許願池**（第五個分頁，2026-11-21 使用者說「許願池的後台移到 admin 後台」，從 `admin_dashboard.html` 搬過來）：登入後跟玩家一起先讀一次 `gaWishes`，分頁名稱後面朱色數字是「還沒處理」（剛投、收到了，沒藏起來）的個數。篩選四顆：還沒處理／在做了／全部／藏起來的。每張卡：頭像、名字、種類・多久前・想要幾個、右上狀態章（收／做／成實心／否淡色）、內容；狀態下拉選單（剛投、收到了、在做了、實現了、不行，一改就存，`gaWishSet { id, status }`）、「藏起來／放回去」（`hidden`）、回一句話＋「存回覆」（`reply`，願望牆看得到，空的就不顯示）。獎金不會因為藏起來收回。
