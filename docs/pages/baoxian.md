# baoxian.html

保險・存：丼步喱人壽的儲蓄險（不在導覽列，從會員中心進來）。載 `line.js`、`wallet.js`。**要 LINE 登入才能投保**（「投保需實名認證」），因為投保、領錢、解約都直接改後端帳號、用後端的時鐘（`policyList`／`policyBuy`／`policyClaim`／`policyCancel`，見 API），手機調時間沒用；頁面的倒數用後端時間減手機時間的差（`offset`）。三種方案（後端 `POLICY_PLANS`，頁面先用頁內一份、登入後用後端回來的 `rules`）：三日・安 3 天 +10%、五日・穩 5 天 +25%、七日・久 7 天 +40%（2026-11-16 使用者從 3／6／10% 調高；利率存在每張保單 `Policies` 的 F 欄，調之前買的照舊利率）；每張 $1 萬～$10 萬，同時最多 3 張。投保扣的錢不算「花掉」；滿期要自己按「領滿期金」，利息記在 `earned.insure`（會員中心寫「丼步喱人壽」）；提早解約沒利息，拿回 70% 起、照經過的時間線性加到 100%（`POLICY_SURRENDER_BASE`），解約前跳業務員挽留（照進度換台詞）。保單是紙本（實物、顏色固定 `--paper` 等，不跟晝夜）：保單號碼、要保人（LINE 名字）、受益人本人、保額、投保／滿期時間、滿期金、進度條、每秒倒數、朱印「承保」（新投保那張蓋下來）；滿期那一刻解約鈕換成會呼吸的「領滿期金」。領錢、解約時畫面中間蓋大章「滿期」／「解約」加金額。結束的保單收在「舊保單」（最近 10 張）。投保、領錢、解約之前先 `Wallet.settle()`（把還沒送的錢包變化送完），後端回來的錢包用 `Wallet.adopt()` 接。條款寫「本公司不理賠前夫造成的任何損失」。
