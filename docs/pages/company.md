## 玩法（照企劃）
- **開場**：三張紙條（可以略過）→ 取公司名字（12 字）→ 送試用期倉鼠小麥 → 雞塊的 3 秒教學案（一定成功，$70）→ 第一張結案單 → 委託板開始每 3 分鐘貼一張（最多 4 張，打廣告多一張）。
- **新手教學泡泡**（使用者 2026-11-25：新手教學不完善）：`S.coach` 一步一步帶，深色泡泡指著下一步要按的地方、那個東西外面一圈青色亮光；每一步都可以「略過教學」。順序：點雞塊的委託 → 點小麥 → 開工 → 看進度等 3 秒 → 點做完那一行收款 → 泡泡指著「公司帳戶」那格，講賺到的錢進哪裡（扣三成薪水、剩下進公司帳戶、搬家用；錢包另外算、可以從公司頁轉進錢包），按「懂了，下一步」（`S.coach = 5.5`，使用者 2026-11-25 要求加的）→ 去員工招募 → 聘一位 → 去委託點一張、按幫我派（教學這一步不預先勾上次的人；挑好後泡泡移到畫面最上面，不擋住打勾的員工）、開工 → 最後說做滿 10 件＋$20,000 可以搬到小辦公室（「知道了」結束）。泡泡在的時候不跳提示膠囊。教學完的第一批三張委託是 `easy`（沒有條件、3 或 12 分鐘、最多 2 人、卡片只寫「新手」（使用者：「一定成功」不要寫出來；派人單子的機率寫「幾乎一定」）：成功機率 100%、不跳突發狀況），教學第 8 步泡泡一定指這種卡。教學那一批應徵的人沒有特別人選（`applicants(..., noSpecial)`），教學中聘第一位時錢包不夠就「公司請客」免簽約金，所以教學不會卡住、也不會失敗（2026-11-25 使用者要求確認；`easycheck.js` 跑 2 萬次、錢包只剩 $500 也走得完）。
- **辦公室會動**（使用者 2026-11-25：辦公室完全靜態）：`CompanyOffice.fx(n)` 給螢幕和燈泡的位置（畫辦公室時順便記下來）。頁面每秒畫約 20 張（`animFrame`，只在辦公室分頁、畫布看得到、頁面在前面時跑；`IntersectionObserver` 看 `#cv`）：燈泡光暈慢慢呼吸、舊燈泡約 9 秒閃一下、光裡有灰塵往上飄、螢幕的字一行一行打（有游標）、做事的員工打字點頭（1px）、閒著的偶爾動一下、茱莉鴨睡著冒 Z、案子做完在第一位員工頭上飄「+$」（做砸是紅的）。
- **執行長增資自己選金額**（使用者 2026-11-25）：按增資打開視窗（`openInject`），中間大字是金額，左右「−1,000」「+1,000」，長按會一直加減；最少 1,000（額度不到 1,000 就是剩下的），最多是「今天還能增資」和錢包的較小值。預設是公司帳戶離搬家還差多少（進位到千；不用搬家就 1,000）。下面有「補到能搬家」「全部」兩顆快捷。
- **公司頁導覽**（使用者 2026-11-25：公司裡的功能也要新手教學）：主教學做完或略過後（`S.coach` 是 0），第一次打開公司頁就帶一圈（`S.ctour` 1～7，`TOUR` 陣列，會自己切分頁）：現在的辦公室／看所有辦公室 → 搬家鈕 → 執行長增資 → 轉進錢包 → 紀念品 → 設備 → 圖鑑（泡泡放最上面）。泡泡右下「下一步 n / 7」、最後「知道了」，左下「略過」。找不到的東西（例如大樓沒有搬家鈕）自動跳過。舊存檔也會跑一次。
- **新人試玩後的修正**（2026-11-25，請一位新人用手機從開場玩到搬家）：
  - 突發狀況的「賭一把」、「說這是故意的」輸了是**整件做砸**（客人只付一成、薪水扣一半），選項文字照實寫「不然做砸，客人只付一成」；結案單寫做砸的原因（`j.why`），賭贏的加成寫「突發狀況・賭贏了」。
  - 開工前的機率叫「**成功機率**」（沒成功＝做砸）；「做得好」只指成功後再多拿一成的運氣，兩個不混用。
  - 委託板：接不了的（同時做滿、閒著的人不夠、沒人合條件）變淡、排到後面，紅字寫原因；一般案子剩不到一小時也顯示「後撤」；上面那行寫做著幾件、閒著幾人；最下面「標籤看不懂？」打開說明（`openHelp()`）。派人的單子寫出標籤的意思（`TAG_TEXT`）。
  - 結案單：委託人、做的人分兩行。試用期做完第一件就轉正（結案單會寫）。
  - 公司頁「轉進錢包」收成小字連結，確認視窗是紅色、寫明轉回來只能靠增資（每天上限）。增資說明寫每天最多多少。
  - 搬家後跳一張「搬家了」卡：新辦公室的圖、位子／同時／案子最長／錢多幾成／新的委託人、新的設備、下一個家的條件。
  - 設備頁寫清楚：這組只在現在的辦公室有用，搬家後換新的一組。所有辦公室的「案子最長 N 小時」取代「跨夜」；還沒搬過家不寫「換成以前的辦公室」那句。圖鑑沒收集的顏色是淡灰小點。
  - 教學：招募那步泡泡放在畫面最上面，不蓋住應徵的人；第一張結案單的說明縮短。
  - 第二位新人試玩後（2026-11-25）：突發狀況寫出「15 秒沒選就照第一個」；突發狀況花的錢（當下從公司帳戶付）在結案單另外寫一行；「看不懂的字」多了毛色、員工的一句話（只是個性）、突發狀況，公司頁最下面也有入口。圖鑑里程碑照企劃做出來：10 格「小動物收容所」、20 格「萬事屋人力銀行」、全部「全員到齊」，每到一格送一次免費換應徵（`S.freeRef`、`S.dexMiles`）。
  - 辦公室小圖（`paintThumbs()`，2026-11-25 使用者：截圖很怪）：整間縮小畫進 96×49 的格子（canvas 3 倍解析、平滑縮小），二十七樓、大樓取最左邊 375 寬（門口、招牌）。圖鑑特別人選格子 68px 高、圖片 `max-width/max-height` 縮進格子。
  - **數字（使用者 2026-11-25 決定）**：搬到小辦公室從 $45,000 調低到 **$20,000**（還是要做滿 10 件；模擬上班族第 0.9 天搬，到大樓還是約兩週）；加班費從案子的兩倍降到**跟案子一樣**（`overtimePrice` = 案子的錢）。
- **委託的小圖不用角色的照片**（使用者 2026-11-25）：照案子名字分九類（卡片、海報、網站、文件、招牌、活動、拍照、書、地圖，`CompanyRules.kindOf(title)` 用關鍵字判斷，沒對到的算文件），每類一個 16×16 像素小圖（放大兩倍）＋一個淡色底，委託卡片和結案單都用這個。對照 `docs/plans/company/job-icons.png`。
- **委託**：卡片寫委託人、長短、幾人、條件、急件／大案／要先談／特好賺（10 分鐘沒接就撤）、系列幾之幾。點卡片派人：條件合不合（誰合）、幫我派、照上次的組合、預計多久、做得好的機率（低於五成開工前再問一次）。
- **上面那條不放錢**（使用者 2026-11-25）：只有「‹ 會員」和標題。錢放在用得到的地方：辦公室三格是公司帳戶、今天賺、進行中（原本的「閒著」拿掉）；員工頁那行寫錢包；設備那頁寫錢包；公司頁的帳戶卡寫公司帳戶和錢包。
- **辦公室**：員工坐在位子上，做事中的人腳下一條進度；進行中列表有倒數、加班費（錢包付，馬上做完）；做完的點一下看結案單，或全部收款。
- **突發狀況**：只有開著畫面才跳（有案子在做時每 4～9 分鐘一次），15 秒沒選就選第一個；選項有多等、花公司帳戶的錢、看談判、賭一把（三成多拿五成，不然要重做）。
- **員工**：最上面一條深色「招募新員工・還能請 N 位」（使用者：招募按鈕不明顯；坐滿了變淺色「看應徵的人」）；分頁上不顯示閒著幾人（使用者：員工不用顯示閒置幾人）。名冊點進去有台詞、能力、本事、經驗、訓練（錢包）、請他走（做事中不行、簽約金不退）。應徵一次三位，每格 5% 是還沒請過的特殊角色，3 小時免費換（倒數每秒跟著跑）、或付錢馬上換（付錢換**不會**重設免費換的倒數，使用者 2026-11-25 定的）；簽約金錢包付；位子坐滿要搬家。
- **角色頭像不切掉**（使用者：紀念品的角色截圖都被切掉了）：紀念品頁的系列列表左邊改放紀念品小圖（沒拿到的是灰的）；員工、應徵、派人的頭像把整隻角色縮進框裡（`.ava img` 最大 100%）。
- **公司**：搬家那一頁**只放現在這間**＋「看所有辦公室 ›」（使用者 2026-11-25：只顯示現在等級，有個地方看所有，解鎖了才亮起，可以換）。所有辦公室那一層五間都列：搬過的亮著、可以「換成這間」；還沒搬到的縮圖灰灰糊糊、銘牌也是灰的，寫要多少錢、幾件、「搬過去才解鎖」。換成以前的辦公室只換畫面（`S.look`），位子、同時幾件還是照現在這間，坐不下的人不畫；辦公室那行寫「（懷舊中）」。搬家時 `S.look` 跟著換成新的。搬家（公司帳戶付＋做完幾件）、執行長增資（錢包 → 公司，每天有上限）、公司帳戶轉進錢包；紀念品（系列五件做完拿，那位委託人之後多拿 5%）、設備（每階三樣、錢包付、每樣 +8%）、圖鑑（41 格）。
- **你不在的時候**：離開超過 10 分鐘回來，跳這段時間做完幾件、可以收多少、誰升級、委託板有幾張。

## 2026-11-25 補完的畫面（使用者：先做 A）
- **員工四種毛色**：一般員工的淺色、花色、深色角色圖是 `assets/company/<種>-c1／c2／c3.png`，用 `docs/plans/company/colors.py` 從本色算出來（只換身體顏色，眼睛、腮紅、坐墊不動；花色是身上幾塊斑）。`spriteKey(s)`：一般員工 `color` 不是 0 就用 `-c<color>`。圖鑑右上角的小點是那一種自己的四個顏色（花色是兩色對半）。
- **設備**：15 樣都有 16×16 像素圖（`EQ_ART`，設備頁小圖和辦公室擺設共用）。買了就畫進那一間辦公室（`EQ_POS`：每間三樣的位置，下緣中間；車庫的電風扇、印表機在桌上，電風扇會轉）。
- **紀念品櫃**：每間辦公室牆上一條小木架（`SHELF`），拿到的紀念品擺上去（沒有就是空架子，最少 3 格寬）。點紀念品 → 委託人說一句話（`CLIENTS.thanks`）。
- **點員工會說話**：點辦公室裡的員工，頭上冒一個對話框 2.8 秒。特別人選說自己的台詞（`SPECIALS.say`），一般員工說自己種類的話（`SPECIES.talk`）。
- **圖鑑格子點開**：收集到的打開一張卡：角色圖（一般員工把收集到的顏色並排）、第一次來應徵的日子、做過幾件、最高等級、一句話；特別人選多寫本事。資料存在 `S.dexInfo[種類]`（聘人時記第一次、結案加件數、升級記等級；舊存檔從現在的員工補）。沒收集到的點了跳提示。
- **門牌用公司名字第一個字**：`CompanyOffice.paint(cv, n, 字)`，字用 12px 思源黑體畫成 12×12 像素字（`rasterGlyph`），五種門牌跟著大 3 格；是「丼」或沒給就用原本 9×9 的丼。字型載好會重畫一次。大樓大廳那個大「丼」不換。
- **夜間模式**：跟全站一樣晚上 10 點到早上 6 點或手機深色時（`<html class="night">`）。介面顏色都改成 CSS 變數（`--ink`、`--sub`、`--teal`…），夜裡換一組深色毛玻璃；深色按鈕變淺色。辦公室整間乘上一層藍灰，燈泡的光和螢幕在上面另外打亮。這頁沒有晝夜切換鈕（照舊藏起來）。
