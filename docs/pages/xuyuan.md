# xuyuan.html

許願・池（2026-11-19 使用者要的「搜集提案的地方，許一個願獎勵 1000」，同一天改成 3000，再改成隨機 3000～6666、網頁上不寫金額）。不在導覽列，從會員中心「參 廟口」進來。載 `theme.js`、`line.js`、`wallet.js`、`avatar.js`；後端網址用 `Line.API_URL`（沒有自己寫死 `API_URL`），沒登入的人直接 `fetch`，登入的走 `Line.call()`。

**規則**（後端 `WISH_*` 常數，改數字只要改後端）：用 LINE 登入才能許願；**每天（台灣日期）第一個願望隨機 $3,000～6,666**（`WISH_REWARD_MIN`／`WISH_REWARD_MAX`，2026-11-19 從 $1,000 → $3,000 → 隨機；**使用者要的：給多少不要寫在網頁的敘述上**（規則、表單提示、會員中心都只寫「有獎金」，`wishList` 也不回金額），領到時的大朱印和提示才寫拿了多少；後端直接加進帳號 `earned.wish`，網頁 `await Wallet.settle()` 再 `Wallet.adopt()`，跟保險一樣）；一天最多 3 個（`WISH_PER_DAY`，後兩個沒有獎金）；4～200 字；同一個人同樣的字不能許兩次；全站每小時最多 60 個。「每人每天第一個願望」是使用者 2026-11-19 確認的（防止洗願望賺錢）。

**畫面**：上面是池子畫布（360×230，實物、顏色固定，背景用 `themeColor('--wabi-bg')`）：石頭圍邊、水、三條錦鯉繞圈、荷葉、池底的古錢（願望數，最多畫 48 枚，位置用固定亂數）；點水面起漣漪；許願成功時一枚硬幣從下面拋進去、濺起漣漪、多一枚，有獎金就蓋大朱印「願」＋金額。畫面迴圈照網站規矩（`nextFrame()`／`startLoop()`、捲出畫面就停、平常每秒約 20 張、動的時候 60 張；`fit()` 大小沒變不重設畫布）。下面「許一個願」：種類四顆（新遊戲 `game`／點子 `idea`／抓蟲 `bug`／其他 `other`，換提示字）、輸入框（16px 字，iPhone 才不會自己放大）、朱色「投一枚硬幣・許願」、今天還能許幾個／獎金領了沒。沒登入是綠色登入鈕。

**願望・牆**（`wishList`，公開）：最新／最多人想要（有人按的才列，**實現了的不列**，2026-11-21 使用者說的，只放在「實現了」）／實現了三個分頁；每張：大頭貼（指定頭像優先，載不到換名字第一個字）、暱稱、多久前、種類、內容、主人的回覆（朱線，「主人・多久前」）、狀態章（收／做／成（實心）／否），「我也想要」（`wishVote`，再按收回，自己的不能按，寫「我許的」）。最下面規則和「獎金是遊戲幣，不能儲值、不能換現金或獎品」。
