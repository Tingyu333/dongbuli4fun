# quede.html

缺德榜（原本的功德榜改的；不在導覽列，目前也還沒有入口，直接開網址）。3 面大匾（`tier: 'big'`，重大刑案）＋ 10 塊罪牌（`small`）：黑漆、裂痕、鐵字，貼著「罪人・待審」封條。點了上「公堂」全螢幕開審：木魚三聲、（大匾）光明燈一盞一盞熄掉、雷劈下來封條炸開、名字一字一字烙上去（每個字自己一層 `.iron`，父層的 `background-clip:text` 遇到在動的子元素會消失）、下雨夾家具碎片和布丁蓋（canvas）、「缺德無量」朱印；大匾多了紅色 LED 跑馬燈「公告 某某 罪狀 缺德無量 請速賠償」。聲音都是 Web Audio 合成（木魚、打雷、咚）。開審後可以「擲杯求原諒」：聖杯 1/2 蓋「赦」、雨停；笑杯、陰杯可以再擲。看過的、赦過的存在 `localStorage`（`dongbuli-quede-seen`／`-pardon`），再點是快速版加「再審一次」；開審中點一下跳過；`prefers-reduced-motion` 直接顯示結果；「重新貼上封條」全部重來。沒名字的是「尚無前科」。漆、鐵、紙是實物，顏色固定用頁內的 `--qd-*`，不跟晝夜切換。**名單目前是頁內的假資料 `CASES`**（`item`、`name`、`crime` 罪狀、`verdict` 判詞），之後要改成後台編輯、從後端讀。
