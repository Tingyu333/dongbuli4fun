# admin_dashboard.html

後台預約列表（`adminList`，含電話、Email、人數、已領票的人）。最上面一行摘要（今晚誰在、待處理幾筆、三十天內入住幾筆），再分三區：「待處理」（待確認且還能改的，卡片＋「確認入住」「婉拒」大按鈕，空的時候叫你喝茶）、「即將入住」、「歷史紀錄」，後兩區各自前端分頁（每頁 10 筆，只有一頁就不顯示）。**手機（md 以下）用卡片**：電話 `tel:`、Email `mailto:` 點了就打／寄，按鈕至少 44px，歷史紀錄預設收起來點標題展開；**電腦版**即將入住、歷史仍是表格，狀態用下拉選單。只列出還能改成的狀態（`next`），改之前先跳確認（改了不能回頭）；改完跳出寄了幾封確認信或取消通知。讀取中、讀取失敗（可重試）都有畫面。通行證失效（`unauthorized`）就回登入頁。最下面另外有「發紅包」（`bonusList`／`bonusCreate`／`bonusClose`，見 `docs/wallet.md`），自己讀自己的，後端還是舊版時只有這一區顯示「要重新部署」，預約名單照常。
