## 畫面

- 整頁是一個 App（沒有網站的導覽列，跟設計稿 `ui-flow.png` 一樣）：上面「← 會員・我」、標題、錢包；下一行朱色小章「島 壹」、幾塊地、再買幾塊升下一階；中間整座島；下面四顆（商店、倉庫、扭蛋、圖鑑，圖示是 `assets/xiaodao/icon-*.png`）。倉庫、扭蛋、圖鑑和商店的載具、家具、衣服分頁現在按了只跳「第幾批開」。
- 晝夜鈕這頁藏起來（會擋地圖），島先只有白天（夜景第六批）。
- **島**：一開始照「自己的地＋能買的地」縮到剛好（`D.bounds()`）；點兩下放大 2.2 倍（再點兩下縮回、或按右上「－」；縮回全島、兩指捏到差不多全島，都會整座島擺回正中間，2026-11-21 使用者說「縮放回來島嶼不會在中間」修的），兩指可以縮放、電腦可以滾輪；放大時右上角小地圖（紅框是現在看的地方），可以拖（拖不出島的範圍）。
- **點有鎖的地**：那一塊變亮、標「這一塊」，下面滑出卡片：幾格、價錢、「再買 N 塊，島升到『貳』：…」，「先不要／買下來」。買了重畫整座島（海岸線長出去）。
- **點設施**：白色虛線框起來，卡片寫名字、第幾階（朱色圓點）、「升級：下一階 $價錢」；還不能升就寫為什麼（島要升到哪一階、還差幾塊地：差的地塊在地圖上塗朱色、下一階的範圍畫朱色虛線）。
- **工地**：還沒蓋、島的等級已經能蓋的設施，地上畫白色虛線框（那一塊整平、不長樹），點了一樣跳卡片可以蓋。
- 卡片蓋到點的東西時，島會往上推（`focus()`）。
- **島升一階**：跳一張「島 貳」的章，寫解鎖了什麼。
- **商店**：分頁「地」（點地圖買、下一塊多少、島的等級表）、「設施」（五種設施一列一列：圖、第幾階、下一階多少、蓋／升級鈕）。頁尾一句「島上的東西都用遊戲幣買，不能儲值，也不能換成現金或任何獎品」（預告畫面也有）。

## 規則（`assets/xiaodao-rules.js`，`XiaodaoRules`）

純計算、不碰畫面，**網頁和之後的後端用同一份**（開放時把整份貼進 `Code.gs`，測試比對兩邊一樣）。

- **世界固定、大家一樣**：一格 20 顆像素，44 × 38 格（880 × 760）。地塊是不規則的一片（格子上撒點、每一格歸最近的點，`SEED` 37），177 塊、平均 8.4 格；太小的（被海切剩一兩格）併到旁邊。世界邊邊兩圈的地塊不能買（「太外海了，船開不到」）。
- **永遠是海**：`SEA`（x 200～720、y 480～620）那片不屬於任何地塊，家蓋到海景別墅要靠這片海、碼頭伸進這片海。
- **設施的位置固定**（每種一個工地，等級越高圖越大，`FAC` 的 `mode` 是怎麼對齊）：家靠右下（海岸線 y 480，往左長）、車庫靠左下（x 480、y 440）、碼頭對齊海岸線（x 560 置中）、停機坪下面置中（x 330、y 340）、發射台下面置中（x 590、y 300）。任兩種設施的任兩級都不會疊在一起（測試）。
- **蓋某一級要先擁有那一級占到的地塊**（`needPlots()`：格子中心在圖裡的那幾格；碼頭只算岸上那一排）。
- **一開始送 13 塊**：帳篷、腳踏車棚、小木台底下的地＋把它們連起來的地；送帳篷（家第一階）。車庫、碼頭第一階各 $2,000。
- **島的等級**（`TIERS`，地塊數含送的）：壹（一開始）家、車庫、碼頭到貳；貳 16 塊：三種到參、可以蓋停機坪（到貳）；參 22 塊：三種到肆、停機坪到參；肆 30 塊：三種到伍、停機坪到肆；伍 40 塊：停機坪到伍、可以蓋發射台（還要停機坪蓋到肆）。全部設施蓋到最高剛好要 40 塊（測試算的）。
- **價錢**：第 n 塊買的地 $1,500 × 1.2ⁿ（第 1 塊 $1,800、第 10 塊約 $9,300、第 20 塊約 $5.7 萬、第 28 塊約 $35.6 萬，買到伍約 128 萬）；設施照企劃書（`FAC.prices`）。
- **存檔**：`{ v: 1, items: [ { id: 'i1', key: 'island', plots: [擁有的地塊], bought: 買過幾塊 }, { id: 'f-house', key: 'house', lv: 1, in: 'i1', at: 'house' }, … ] }`。設施的 `at` 現在是工地的名字（位置固定），之後開放移動改成座標就好；之後的車、家具也放在 `items`（`clean()` 會原樣留著不認得的）。逛別人的島之後要做的話，就是讀別人的這一份。
- `apply(state, { t: 'plot', p } | { t: 'build', k }, 錢包)` → `{ ok, cost, state, tierUp }` 或 `{ ok: false, err }`；`plotInfo()`、`facInfo()` 給畫面寫「能不能買、差什麼」；`worth()` 是小島值多少（身價・榜用）。

## 畫島（`assets/xiaodao-draw.js`，`XiaodaoDraw`）

- 照定稿的 `docs/plans/jiayuan/island-stages.html`：陸地照擁有的地塊模糊一下再切（海岸線圓滑、沙灘、浪花、淺灘、深海）、梯田一樣的高低、高處岩岸和大石頭、空地自動長樹林；設施、小路、工地底下整平。地塊的邊：自己的地之間淡淡白點，能買的地灰色虛線＋鎖。
- **小路**：從家門口走到每個蓋好的設施門口（只走自己的陸地、繞開設施，8 方向 BFS 再畫成彎彎的），島「參」以前是土路、之後是石板路。跨海的橋還沒做（地都要相連著買，目前用不到）。
- 地形、樹、路畫在一塊像素陣列再一次貼上（不用 `fillRect` 一顆一顆畫），整座島重畫一次約 0.15～0.2 秒，只有買地、蓋東西時重畫；拖、縮放只是把畫好的圖搬來搬去。
- **設施的圖**：`assets/xiaodao/<設施><級>.png`（23 張），從各設施設計圖畫出來再裁（`tools/xiaodao/dump_empty.js` 畫成「空的」：樹不畫、車船飛機火箭換成同樣大小的白色虛線空位；`tools/xiaodao/crop.py` 把草地（碼頭、別墅連沙灘和海）變透明、裁到剛好）。改了設計圖就照這兩支重跑。
- **車位、泊位、機位的位置**：`dump_empty.js` 順便記在 `tools/xiaodao/slots.json`（每一階每一台原本畫在哪、多大），第二批要用。
